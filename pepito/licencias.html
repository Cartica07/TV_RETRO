Código fuente y componentes con licencia de copyleft

Algunos componentes del programa del dispositivo (el Arduino core para ESP32, con licencia LGPL 2.1, y las tipografías GNU FreeFont, con licencia GPL con excepción de fuentes) exigen poner a disposición su código fuente y la posibilidad de reconstruir el programa con versiones modificadas de esos componentes. El código fuente de esos componentes es público (ver las fuentes de la lista de esta página). Quien lo solicite por escrito al correo de contacto recibirá, durante al menos tres años desde la distribución del dispositivo, los archivos necesarios para volver a construir el programa con una versión modificada de esos componentes, y el texto completo de cada licencia. El código propio de Pepito no es de código abierto y no se publica.
